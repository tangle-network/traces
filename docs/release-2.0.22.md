`traces behavior` attributes tool calls across recordings that mix explicit sessions, OTLP agent trees and in-stream workers. The CLI and SDK expose the number of attributed calls, the number of unique input spans and known gaps. Replayed spans count once. A branch selector stays within its source trace when independent producers reuse span IDs.

Runtime directory reads combine bound native sessions, retained OTLP and journal evidence per node. A child can contribute a distinct execution or an exclusive meter even when another node has a native transcript. The reader reports ambiguous ownership and preserves empty or unreadable node boundaries alongside readable work.

Review banks can attach dimension IDs to each question. Answers retain those IDs, including when a question fails.
